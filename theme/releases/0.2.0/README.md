## हिन्दी

54 तैयार थीम, छह परिवार और दो उच्च-कॉन्ट्रास्ट विकल्प। हर परिवार के छोटे समूह में उसके एक्सेंट मिलते हैं। हिन्दी नाम थीम चयनकर्ता और पैनलों में एक जैसे हैं।

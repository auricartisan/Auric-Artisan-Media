## 2. Auric Artisan Modern Icon

### LinkedIn

At 16 pixels, every shape has to earn its place.

Auric Artisan Modern Icon is a production-grade file and folder system designed specifically for developer IDEs. Its full-bleed file silhouette leaves more room for the identifying glyph, while folders use a clearly different form so recognition never depends on color alone.

The system includes **720 library icons**, 193 file icons, 114 folder pairs, state overlays, and framework packs for Angular, NestJS, React/Redux, and Vue/Pinia.

It is also configurable: folder colors, saturation, opacity, associations, icon packs, and content-aware behavior can adapt to the way a project is organized.

## 3. Auric Artisan Icon Library

### LinkedIn

Three icon collections. One shared Icon Studio.

Auric Artisan Icon Library is the infrastructure connecting Modern, Drawn, and Playful into one coherent workflow. When the extensions are installed together, they share a single searchable experience instead of creating duplicate panels.

The Studio lets you search, preview, inspect, insert, or copy icons in the format your project needs—including raw SVG, JSX, React components, HTML/Markdown, and CSS data URLs.

Behind the interface is a shared runtime, validated provider discovery, co-install coordination, generated catalogs, packaging automation, and integration testing.

## 4. Auric Artisan SVG

### LinkedIn

The part people see is the icon. The part that makes it trustworthy is the pipeline behind it.

Auric Artisan SVG starts with editable 64 × 64 masters and deterministically produces color, outline, filled, and small variants—along with transparent PNGs, React and Vue components, Web Components, sprite sheets, CSS classes, searchable metadata, previews, and validation reports.

The current plan covers **1,225 original concepts** across 24 delivery categories, with a hand-authored reference set establishing the visual language before production batches are reviewed.

Validation checks more than whether a file opens: it covers palette rules, stroke widths, safe areas, accessibility, transparency, dimensions, stale outputs, and geometry duplication.
